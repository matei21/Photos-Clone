# PhotoClone - Face Clustering Report

## Overview
This project implements a Google Photos-style face clustering system. It uses state-of-the-art Computer Vision models to detect faces, generate high-dimensional embeddings, and cluster them based on visual similarity.

## System Architecture

### 1. Frontend (React + Vite)
- **Modern UI**: A clean, Google Photos-inspired interface.
- **Upload System**: Multi-file upload capability that sends images to the backend.
- **Cluster Visualization**: Displays detected people as groups of faces. Each face links back to the original image.
- **Actions**:
  - `Upload Photos`: Sends raw images to the server.
  - `Analyze & Cluster`: Triggers the backend clustering pipeline (DBSCAN).

### 2. Backend (FastAPI + Python)
- **Image Storage**: Uploaded images are stored in `backend/faces/`.
- **Face Detection (YOLOv8)**: 
  - Uses `ultralytics` YOLOv8.
  - Specifically configured with `yolov8n.pt` for ultra-fast inference on edge devices.
  - Robust face cropping with bounding box validation.
- **Feature Extraction (FullFaceNet / ResNet50 + ArcFace)**:
  - **Architecture**: Implements the **FullFaceNet** architecture consisting of a **ResNet50 backbone** (ImageNet pre-trained) and a custom **EmbeddingHead**.
  - **Backbone**: Utilizes a frozen/fine-tuned ResNet50 for robust feature extraction.
  - **Embedding Head**: A specialized head with LayerNorm, ReLU, and an orthogonal-initialized Linear layer that maps features to the 128D embedding space.
  - **Normalization**: Applies L2-normalization to the output 128D vectors to ensure they lie on a unit hypersphere.
  - **Inference**: Each face is resized to 224x224 and normalized before passing through the ResNet-based backbone.
- **Vector Database (Qdrant)**:
  - Stores 128D embeddings and metadata (filename, original name, cluster ID).
  - Uses **Cosine Distance** for similarity matching.
- **Clustering (DBSCAN)**:
  - Density-based clustering that automatically discovers the number of unique individuals.
  - Configured with `eps=0.35` and `metric='cosine'` for optimal face grouping.

## Technical Implementation Details

### FullFaceNet Architecture
The backbone is built on **ResNet50**, a powerful residual network that excels at hierarchical feature extraction. The final 2048-dimensional feature vector is processed by a custom **EmbeddingHead** (Linear-LayerNorm-ReLU-Dropout-Linear) that maps it to a discriminative 128D space.

### Optimized Inference Pipeline
1. **Detection**: YOLOv8 extracts face candidates.
2. **Alignment/Cropping**: Faces are cropped and preprocessed.
3. **Embedding**: FullFaceNet (ResNet50) generates a unique 128D signature.
4. **Storage**: Qdrant indexes the signature.
5. **Clustering**: DBSCAN groups signatures into "People".

## How to Run

### Prerequisites
- Python 3.10+
- Node.js & npm
- Virtual environment (recommended)

### Running the System
1. **Start the Backend**:
   ```bash
   # Navigate to the root directory
   .venv/Scripts/python.exe backend/main.py
   ```
2. **Start the Frontend**:
   ```bash
   # In a new terminal
   cd frontend
   npm run dev
   ```
3. **Usage**:
   - Open `http://localhost:5173` in your browser.
   - Click "Upload Photos" and select your images.
   - Click "Analyze & Cluster" to see the results.
